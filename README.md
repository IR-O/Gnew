# Telegram Games Bot

A bot that allows playing multiple games in Telegram groups.

## Features

- 12+ different games
- Simple and intuitive interface
- Multiplayer support for some games
- Score tracking

## Games Available

1. Tic Tac Toe
2. Hangman
3. Quiz
4. Rock Paper Scissors
5. Dice Roller
6. Guess the Number
7. Word Chain
8. Memory Game
9. Blackjack
10. Trivia
11. Crossword
12. Wordle
